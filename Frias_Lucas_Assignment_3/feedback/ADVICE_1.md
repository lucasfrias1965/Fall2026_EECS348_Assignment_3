## 1. Prolog Comments (0/7) — `src/human.cpp` lines 1–7

Current header:

```cpp
// ceo_inbox.cpp
// EDITED BY LUCAS FRIAS
// - added comments and fixed code to use vectors.
// - sender category is now a uint8_t enum instead of a string.
// prioritizes emails for a ceo using a hand-built max heap.
// build: g++ -std=c++11 -Wall -Wextra -o ceo_inbox ceo_inbox.cpp
// run:   ./ceo_inbox inbox.txt
```

The rubric requires 7 specific items: program name, brief description, inputs, output, collaborators, author's full name, creation/revision date. You have name, description, and author (loosely, via "EDITED BY"). Missing: **inputs, output, collaborators, date** — 4 missing items trips the "more than 2 missing" bucket (0 pts), when fixing it is a 10-minute edit.

Suggested replacement:

```cpp
/*
 * Program:       ceo_inbox.cpp
 * Description:   Prioritizes a CEO's inbox using a hand-built, vector-based
 *                MaxHeap (sender category, then newest-date tiebreak).
 * Input:         Path to a command file (EMAIL/NEXT/READ/COUNT lines) passed

 *                https://stackoverflow.com/questions/849168
 * Author:        Lucas Frias
 * Created:        <fill in actual date you first wrote this>
 * Revised:        2026-10-01 — switched raw array to std::vector, string
 *                category to enum class Category, per Opus 5.5 pairing

 * Run:           ./ceo_inbox inbox.txt
```

Fill in the real creation date — "Revised" alone won't satisfy the "creation/revision date" item if a grader reads it as only a revision log with no origin date.
